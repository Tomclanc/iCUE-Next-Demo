# 原版 iCUE 外观增量修复 · 2026-11-02

这次更新修正原版 iCUE 亮色改造中遇到的托盘和设备卡片问题。原来的 15:23 Demo、小组件安装包和截图保持不变。

**这是已有 CueAppearance 主题模块的增量补丁，不是完整主题安装器。** 需要 Windows 11 x64、iCUE 5.52.93，以及已经安装的 `imports/CueAppearance` 模块（包括 AppearancePlugin.dll、qmldir、icue-app.png）。本包不提供该前置模块，也不适用于全新安装的官方 iCUE。脚本会拒绝缺少前置模块或 DLL 校验不符的环境。

## 修改内容

- 托盘主菜单、配置文件子菜单和悬停项统一亮／暗配色。
- 对真正的 `CUETrayMenu` 窗口应用圆角裁剪，同时处理标题自动附加 ` - iCUE` 的子菜单。菜单内容画圆角但窗口仍有方底的问题由窗口层处理。
- 默认配置文件图标使用现有主题模块中的透明底图片，与主界面左上角一致；去掉图标的黑色方底。
- 设备卡片的普通、悬停背景直接使用主题对应颜色，保留展开动画。
- 只绕开 DeviceCard 的旧 AOT 缓存入口，让修改后的 QML 真正加载，其他页面继续使用原有编译缓存。
- 正常打开主窗口，不再把用户界面按隐藏窗口方式启动。

圆角由小型 `TrayCorners.exe` 辅助程序处理。它只匹配指定 iCUE 路径下的托盘窗口，监听窗口显示／位置变化，并用定时检查补充。安装会在当前用户启动目录创建 `iCUE Tray Corners.lnk`；不安装服务，不联网。

## 安装与回退

需要 Python 3（只使用标准库）和 Windows 自带的 .NET Framework 4.x C# 编译器。

在解压目录运行：

```powershell
powershell -NoProfile -File .\Install.ps1
```

脚本先验证并生成补丁、编译圆角辅助程序，再请求 Windows 管理员确认。安装期间会重启 iCUE。修改前的本机 DLL 与 qmldir 保留在 `.backup`；受影响的 QML 缓存移入备份目录。请保留整个补丁目录，供回退使用。

```powershell
powershell -NoProfile -File .\Install.ps1 -Restore
```

回退恢复首次运行本包时保存的文件，停止辅助程序并移除其启动快捷方式。不会清空设备配置、修改风扇曲线或卸载前置主题模块；辅助程序及未使用的 TrayTheme.qml 文件可能保留在磁盘上。若初次安装本包时已是相同修复版，备份也会是修复版。

本包只包含补丁数据、自编辅助程序源码和安装工具，**不包含完整 CORSAIR DLL、用户配置、日志、传感器快照或签名私钥**。补丁校验锁定具体构建；官方更新后不能强行套用。

## 同次排查：设备和小组件

这些配置问题与外观补丁分开处理，安装器不会自动修改它们。

**RDP 下设备消失、冷却液未提供：** 本机日志显示切换远程桌面后 iCUE 禁用了设备枚举。退出 iCUE，备份 `%APPDATA%\Corsair\CUE5\config.cuecfg`，在现有 `<map name="Devices">` 中增加或更新以下值，然后重新启动，可允许远程会话访问设备：

```xml
<value name="AllowRemoteSessionControl">true</value>
```

仅在需要远程会话控制时启用，不要重复创建 Devices 节点。它是 iCUE 配置项，不是 UI 隐藏故障的通用修复。

**GPU 一行变成 `id:… — 未提供`：** 重启后测点 ID 可能变化。小组件选项改用 `GPU 温度` 自动匹配，而不是旧 `id:`。例如在现有 `%LOCALAPPDATA%\Corsair\iCUEAppearancePatch\widgets.json` 中只修改对应字段：

```json
"widgetSensor2": "GPU 温度"
```

这只是配置片段，请保留其他字段。多显卡场景未做通用匹配保证。
